# Experiment Overview

## zaragoza_efficiency_real_sample
Measures whether a packaged reconstruction method runs end-to-end on a bundled real Zaragoza-style confocal sample and reports runtime and memory in the same units as the paper's public efficiency claim.

## complexity_scaling_cubic_measurements
Measures whether the packaged method exhibits the working-memory trend described in Table 1 when the input is an N x N x N confocal measurement cube. The focus is the difference between the standard and lower-memory execution paths, especially the reduction in working-memory order.
